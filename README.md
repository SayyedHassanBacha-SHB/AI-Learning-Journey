# AI Learning Journey

A structured, hands-on journey into Artificial Intelligence, from Python fundamentals and data analysis to machine learning, deep learning, and modern AI systems.

This repository documents my learning progress, practical implementations, experiments, and projects as I work toward becoming an AI engineer.

## About This Repository

I am a BS Information Technology student building a strong foundation in Artificial Intelligence through structured learning and practical implementation.

My approach is to learn the theory, implement the concepts in Python, and apply them through projects.

I am following a combination of MIT courses, mathematical foundations, and practical AI resources, gradually progressing from programming fundamentals to advanced AI systems.

## Learning Approach

Each phase follows three parallel tracks:

1. **Theory:** Understand the underlying concepts and mathematical foundations.
2. **Implementation:** Use Python and relevant libraries to implement what I learn.
3. **Projects:** Apply the knowledge through practical exercises and projects.

My learning cycle is:

Learn → Understand → Implement → Build → Improve

## Upcoming Learning Phases

The following phases represent my planned learning roadmap.

### Phase 03 — Classical Artificial Intelligence

Search algorithms, state-space problems, graph traversal, and adversarial search.

Planned implementations: BFS, DFS, Uniform Cost Search, A*, Minimax, Sudoku Solver, and Maze Solver.

### Phase 04 — Linear Algebra

Matrix operations, dot products, eigenvalues, eigenvectors, and Singular Value Decomposition (SVD).

Planned projects: Matrix Calculator, Image Compression using SVD, PCA from Scratch, and Basic Face Recognition.

### Phase 05 — Probability

Probability distributions, random variables, Bayes' theorem, expectation, variance, and sampling.

Planned projects: Dice Simulator, Monty Hall Simulation, and Naive Bayes Spam Classifier.

### Phase 06 — Calculus

Derivatives, partial derivatives, gradients, and optimization.

Planned projects: Derivative Calculator, Gradient Descent Visualization, and Function Optimizer.

### Phase 07 — Multivariable Calculus

Gradients, tangent planes, cost surfaces, and multivariable optimization.

Planned projects: Gradient Visualization and Gradient Descent from Scratch.

### Phase 08 — Statistics

Regression, sampling, confidence intervals, hypothesis testing, and ANOVA.

Planned projects: Student Score Analysis, Housing Price Analysis, Sales Prediction, and Customer Behavior Analysis.

### Phase 09 — Deep Learning

Neural networks, backpropagation, CNNs, RNNs, LSTMs, Transformers, and optimization.

Planned projects: MNIST Digit Recognition, Cats vs. Dogs Classification, Flower Classification, and Emotion Detection.

### Phase 10 — Natural Language Processing

Text preprocessing, language models, text classification, and transformer-based NLP.

Planned projects: Spam Detection, Sentiment Analysis, Text Summarization, Question Answering, and Chatbots.

### Phase 11 — Computer Vision

Image processing, classification, object detection, segmentation, and OCR.

Planned projects: Face Detection, Object Detection, Image Segmentation, License Plate Detection, and Pose Estimation.

### Phase 12 — Large Language Models

Transformer architectures, model inference, fine-tuning, and parameter-efficient fine-tuning.

Planned projects: PDF Chatbot, Document Question Answering, Research Assistant, and LLM Fine-Tuning using LoRA.

### Phase 13 — Retrieval-Augmented Generation

Embeddings, vector databases, semantic search, retrieval pipelines, and grounding LLM responses in external knowledge.

Planned projects: Private Knowledge Assistant, Research Assistant, University Chatbot, and Company Knowledge Base.

### Phase 14 — AI Agents

Tool calling, agent workflows, planning, memory, and multi-agent systems.

Planned projects: Research Agent, Travel Planner, Coding Assistant, and Customer Support Agent.
